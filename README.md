## Overview

This repository presents a complete Python-based mean-reversion backtest framework on two European ETF symbols (EZU and VGK). It covers:

* **Data acquisition**: Automatic download of historical price data via `yfinance`.
* **Strategy implementation**: Simple mean-reversion using 30-day SMA signals.
* **Transaction cost modeling**: 0.1% commission per trade.
* **Performance metrics**: Annualized Sharpe Ratio and Maximum Drawdown.
* **Reporting**: Automated generation of HTML and PDF analysis reports.

The project is designed to be a template for quant strategy research and portfolio construction.

## Quick Start

```bash
# 1. Clone the repository
git clone git@github.com:zuoyi666/mean_reversion_strategy.git
cd mean_reversion_strategy

# 2. Create and activate Conda environment
conda create -n quant python=3.11 -y
conda activate quant

# 3. Install dependencies
pip install -r requirements.txt
playwright install

# 4. Download data and run backtests
python src/download_data.py
python src/mean_reversion_backtest.py

# 5. Generate analysis report
jupyter nbconvert --execute --to html notebooks/mean_reversion_analysis.ipynb
open notebooks/mean_reversion_analysis.html
```

## Results

The backtest and the notebook report the annualized Sharpe ratio and the maximum drawdown of each ETF strategy. The numbers are regenerated by `src/multi_backtest.py` and the notebook; they are an illustration of the mechanics of a single-asset, in-sample backtest and are not a performance claim.

## Relationship to Quant Research Lab (QRL)

This repository is the first (2025) prototype in a line of three projects: this single-asset backtest, then the two-repository pipeline [news-to-signal](https://github.com/zuoyi666/news-to-signal) and [cost-aware-backtest](https://github.com/zuoyi666/cost-aware-backtest) (2026), then Quant Research Lab (QRL), a separate project that redesigns the research workflow under a research charter written before any results were seen. QRL does not reuse this code; it builds on the problems this prototype exposed.

| Topic | mean_reversion_strategy (this repo) | QRL |
|---|---|---|
| Scope | Two European ETFs, one fixed 30-day SMA mean-reversion rule | A point-in-time S&P 500 cross-section, pre-specified signal families and baselines |
| Evaluation | One in-sample backtest per ETF; Sharpe ratio and maximum drawdown | Purged expanding-window walk-forward, an untouched lockbox, Newey-West inference, negative controls and a known-answer test |
| Costs | 0.1% commission per trade | 10 bps one-way on net traded notional, 50 bps a year borrow, dividends owed on shorts, plus a sensitivity grid |
| Data | Public price data downloaded with yfinance | A licensed academic market database (kept private), plus a fully synthetic demonstrator |

What carried over:

- Charging a cost on every trade and reporting gross and net separately. QRL keeps that discipline and adds netting of overlapping positions before costs are charged.
- Sharpe ratio and drawdown as the headline metrics. QRL pairs them with a prediction-quality metric (rank IC with a HAC interval) so that prediction quality and portfolio quality are judged separately.
- The lesson that a single in-sample backtest cannot support a claim, which is why QRL freezes its validation dates and decision rules before looking at results.

QRL's repository is currently private.

### Known limitations at a glance

- In-sample only: no validation split, no out-of-sample period and no parameter selection procedure.
- A single fixed rule on two ETFs; no cross-section, no universe definition and no point-in-time data.
- yfinance data are convenience data, not research-grade history.
- Results illustrate the mechanics and are not performance claims.
